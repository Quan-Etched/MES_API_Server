Upload a file (Excel / JSON / YAML)

curl -X POST {{ base }}/api/v1/iec/upload \{% if auth_enabled %}
  -H "X-API-Key: $KEY" \{% endif %}
  -F "file=@L6_wip_20261101.xlsx" \
  -F "submitted_by=BING" \
  -F "source_tz=Asia/Bangkok" \
  -F "data_type=auto"

Form fields: file, data_type (auto or a key below), sheet_map (JSON, e.g. {"Sheet1":"wip","Sheet2":"skip"}), submitted_by, source_tz, note, strict (Etched only).

Send JSON directly

curl -X POST {{ base }}/api/v1/iec/upload \{% if auth_enabled %}
  -H "X-API-Key: $KEY" \{% endif %}
  -H "Content-Type: application/json" \
  -d '{
  "source_system": "INVENTEC_MES",
  "submitted_by": "BING",
  "source_tz": "Asia/Bangkok",
  "data_type": "wip",
  "records": [
    {"unit_sn": "LV5ARP0046", "current_station": "IV-ICT-01",
     "in_ts": "2026-11-01 10:20:00", "wip_status": "QUEUE"}
  ]
}'

Several types in one call: {"data": {"unit": [...], "genealogy": [...]}}. YAML: same structure with Content-Type: application/x-yaml.

  "status": "RECEIVED",                 // RECEIVED | RECEIVED_WITH_ERRORS | COMMITTED | PARTIAL | REJECTED
  "inserted_rows": 1,

  "sheets": [{
    "sheet": "wip", "data_type": "wip", "missing_required": [], "unknown_columns": [],

    "errors": [ {"row_no": 3, "field": "in_ts", "message": "not a date/time: 'abc'"} ]
  }]
}

HTTP 200 = stored, 400 = unreadable payload, 401 = bad key, 413 = too large, 422 = Etched batch rejected (strict).
