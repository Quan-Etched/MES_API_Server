# MES_API_Server

Verification server for the Inventec (IEC) and Etched L6 database interface. Flask + SQLite, English UI. BING uploads Excel or JSON so each column can be checked against the Etched L6 schema.

## Run

```powershell
cd C:\Projects\Inventec_MES\MES_API_Server
.\run_local.bat
```

Open http://127.0.0.1:5050
