Etched · Manufacturing Test

Inventec MES ⇄ Etched L6 Integration Sandbox

Interface verification between Inventec (IEC) MES and the Etched L6 manufacturing database. Upload Excel or JSON, check that every column matches an Etched L6 field, preview the rows, then submit. Data received from Inventec is stored in separate iec_* staging tables and never written directly into the Etched core tables.

Inventec MES Import → IEC → Etched · work orders, units, genealogy, WIP, station history, test results, QC, rework, material lots Etched Test Results Upload → Etched → IEC · station results, measurements, identities / provisioning

How to verify

  1. Download a template from the L6 Data Dictionary, or use your own file.
  2. Choose Excel or JSON, select the file and click Validate & Preview.
  3. Review the field mapping: EXACT ALIAS UNMATCHED, missing required fields and row errors.
  4. Click Submit. A batch ID is returned; see Upload History.
